- Published the documentation as a static site on GitHub Pages. [[Publishing]]
	- The same UI the desktop app embeds now builds around a graph on disk when `QUIDDITY_STATIC_GRAPH` is set. [[Static build]]
	- CI imports `docs/` with `quiddity-node`, builds the UI around the result and deploys it.
	- The site is the UI showing its own documentation, so this page is the real thing, not a mock-up.
- Things worth remembering
	- Panes only render in the browser, so the HTML is a shell and the content arrives after load.
	- Edits on the site live in the page and are lost on reload.
	- Actions in workflows must be pinned to hashes (zizmor insists), and the first push to the workflow was red for exactly that.
- Held back typing that nobody can see. [[Publish gate]]
	- `Peer::edited` saves at once but sends only if another device has the block open, or once the edit is over.
	- Saving must not wait, so "the graph changed" and "send the changes" are separate signals.
- The repository moved to `quiddity-app/quiddity`, and the crate metadata now says so.
- Things worth remembering
	- The UI runs `View` in the browser and the shell holds the native graph, so nothing in `View` can reach a `Peer`. The gate will be driven by commands from the UI to the shell, once the shell runs a peer. [[Presence]]
